# 이 사이트 보안 몇 점?

> 아이디어 #1 · 보안 관련

사이트 주소를 넣으면 HTTPS·보안 헤더·메일 위조 방지·도메인 보호를 살펴 보안 점수와 고치는 법을 알려 주는 웹. 공개된 응답만 보고 공격성 검사는 하지 않음. 덤으로 비밀번호 검사·스미싱 퀴즈.
